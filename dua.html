About Duʿā Garden

This single-file app combines an embedded, carefully referenced duʿā library with the public Al Quran Cloud API for live Qur'anic verse verification and recitation. It works offline for the built-in library after the page is saved; live verification and audio require internet.

Important: No public API reliably provides every duʿā from every hadith collection with universally agreed grading. This app therefore avoids claiming total completeness and prioritizes widely accepted supplications.
